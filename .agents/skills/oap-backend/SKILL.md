# OAP Backend Skill

## Principles

Work only within the requested scope and read only the minimum required files.

Follow the existing project architecture and modify only the layers required by the task.

Check DB and API impact before changing them.

Prefer the smallest correct diff and avoid unrelated refactoring or regeneration.

Never create duplicate migrations.

Never modify environment files or secrets unless explicitly requested.
